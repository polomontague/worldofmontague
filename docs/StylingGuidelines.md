# Styling Guidelines

All components must use StyledComponents

# Main App
* Has var(--black) background color
* Has var(--serif) font
* Has var(--font-size) sized text
* Has var(--white) text color
* Has var(--letter-spacing) spacing between text letters
* Has var(--line-height) text line height

## Text Fields
* Are 100% width
* Have var(--field-size) height
* Have var(--spacing-medium) padding on the left and right
* Have var(--very-dark-grey) background
* Have a var(--border-width) width, var(--dark-grey) colored solid border
* Have a var(--border-radius) border radius
* Have var(--serif) text
* Have var(--font-size) text size
* Have var(--white) colored text
* Have var(--icon-size) width/height square icons
* Have var(--white) colored icons

## Placeholders
* Have var(--serif) font
* Have var(--font-size) text size
* Have var(--grey) colored text
* have var(--grey) icons

## Buttons
* Are 100% width
* Have var(--field-size) height
* Have vertically and horizontally centered text
* Have var(--white) background
* Have all caps text
* Have var(--serif) font
* Have var(--button-font-size) text size
* Have var(--black) colored text
* Have no text underline
* Have var(--icon-size) width/height square icons

## Nested Buttons (Buttons inside var(--field-size) height fields)
* Have (var(--field-size) - var(--inner-field-size)) / 2 spacing to center the button inside the parent field equally on all sides
* Have var(--spacing-small) spacing between elements inside outer spacing
* Have all caps text
* Have var(--serif) font
* Have var(--button-font-size) text size


## Disabled States
* Have var(--very-dark-grey) background
* Have a var(--border-width) width, var(--dark-grey) colored solid border
* Have var(--grey) colored text
* Have var(--grey) colored icons
